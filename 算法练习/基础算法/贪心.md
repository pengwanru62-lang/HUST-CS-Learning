# 贪心算法

## 1. 核心思想

> 每一步都选择当前看起来最优的方案，并希望通过局部最优得到全局最优。

贪心算法通常具有以下特点：

- 每一步只考虑当前最优选择
- 做出选择后一般不撤销
- 逐步构造最终答案
- 必须证明局部最优能够推出全局最优

---

## 2. 解题关键

做贪心题时，重点回答两个问题：

1. 当前这一步在“贪”什么？
2. 为什么这个局部最优一定能得到全局最优？

> 贪心不能只凭感觉使用，必须证明正确性。

---

## 3. 常见解题流程

```text
分析题目目标
    ↓
设计局部最优策略
    ↓
排序或使用优先队列
    ↓
按照策略逐步选择
    ↓
证明策略正确
```

常用工具：

```cpp
sort();
priority_queue;
```

---

## 4. 常见证明方法：交换论证

交换论证的基本思路：

1. 假设最优方案中存在不符合贪心规则的两个相邻元素
2. 将它们交换
3. 证明交换后答案不会变差
4. 不断交换，最终得到符合贪心规则的最优方案

---

## 5. 例题：P1223 排队接水

### 5.1 题目目标

使所有人的平均等待时间最小。

因为人数 `n` 固定，所以：

```text
平均等待时间最小
等价于
总等待时间最小
```

### 5.2 贪心策略

> 接水时间短的人优先。

如果接水时间相同：

> 编号小的人优先。

### 5.3 正确性证明

假设两个人的接水时间分别为：

```text
x > y
```

如果 `x` 排在 `y` 前面：

```text
两人产生的额外等待时间 = x
```

如果 `y` 排在 `x` 前面：

```text
两人产生的额外等待时间 = y
```

因为：

```text
y < x
```

所以短时间的人排在前面更优。

因此最终应按接水时间从小到大排序。

## 7. 计算总等待时间

维护两个变量：

```cpp
long long wait = 0;
long long total = 0;
```

遍历排序后的所有人：

```cpp
total += wait;
wait += 当前人的接水时间;
```

含义：

- `wait`：当前人之前所有人的接水时间总和
- `total`：所有人的等待时间总和

平均等待时间：

```cpp
double average = 1.0 * total / n;
```

保留两位小数：

```cpp
cout << fixed << setprecision(2) << average;
```

#### 经典例题 P1223[排队接水](https://www.luogu.com.cn/problem/P1223 "排队接水")
```cpp
#include<bits/stdc++.h>
using namespace std;

struct Person{
    int time;
    int id;
};  //用结构体来维护id和time的匹配便于排序

const int N = 1005;
Person a[N];

bool cmp(const Person& x, const Person& y){
    if(x.time != y.time)
        return x.time < y.time;

    return x.id < y.id;
}//指定结构体的排序函数

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    for(int i=1; i<=n; i++){
        cin >> a[i].time;
        a[i].id = i;
    }  

    //排序
    sort(a+1, a+n+1,cmp);

    //贪心计算
    long long total=0; //维护total
    long long wait=0;  //维护前一个的wait

    for(int i=1; i<=n; i++){
        total+=wait;
        wait+=a[i].time;
        cout << a[i].id << " ";
    }

    cout << "\n";
    
    double aver = (double)total/n;

    cout << fixed << setprecision(2) << aver << "\n";
    
    return 0;
}
```

#### P1208 [[USACO1.3] 混合牛奶 Mixing Milk](https://www.luogu.com.cn/problem/P1208 "[USACO1.3] 混合牛奶 Mixing Milk")
```cpp
#include<bits/stdc++.h>
using namespace std;

struct Farmer{
    int price;
    int num;
};

bool cmp(const Farmer& x, const Farmer& y){
    if(x.price != y.price)
        return x.price < y.price;

    return x.num > y.num;
}

const int N = 5005;
Farmer a[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,m;
    cin >> n >> m;

    for(int i=1; i<=m; i++){
        cin >> a[i].price >> a[i].num;
    }

    sort(a+1, a+m+1, cmp);

    int total_num = 0;
    int total_price = 0;

    for(int i=1; i<=m; i++){
        total_num+=a[i].num;
        if(total_num >= n){
            total_price += (a[i].num+n-total_num ) * a[i].price;
            break;
        }else{
            total_price += a[i].num * a[i].price;
        }
    }

    cout << total_price;
    
    return 0;
}
```
#### P1094 [[NOIP 2007 普及组] 纪念品分组](https://www.luogu.com.cn/problem/P1094 "[NOIP 2007 普及组] 纪念品分组")(排序+贪心+双指针)
```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 3e4 + 5;
int a[N];

int main(){
    ios::sync_with_stdio(false);

    cin >> w;

    int n;
    cin >> n;

    int l=1;
    int r=n;
    int ans=0;

    while(l<=r){
        if(a[r]+a[l] > w){
            r--;
        }else if(a[r]+a[l] <= w){
            r--;
            l++;
        }
        ans++;
    }
    cout << ans;
    return 0;
}

### 8.2 区间贪心

常见策略：

```text
按右端点从小到大排序
```

常用于：

- 选择最多不相交区间
- 活动安排
- 会议安排
#### P1803 [凌乱的yyy / 线段覆盖](https://www.luogu.com.cn/problem/P1803 "凌乱的yyy / 线段覆盖")
```cpp
#include<bits/stdc++.h>
using namespace std;

struct Match{
    int start;
    int end;
};

bool cmp(const Match& x,const Match& y){
    if(x.end != y.end)
        return x.end < y.end;
    return x.start < y.start;
}

const int N = 1e6 + 5;
Match a[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    for(int i=1; i<=n; i++){
        cin >> a[i].start >> a[i].end;
    }

    sort(a+1, a+n+1, cmp);

    int lastend = -1;
    int ans = 0;
    
    for(int i=1; i<=n; i++){
        if(a[i].start >= lastend){
            ans++;
            lastend = a[i].end;
        }
    }
    cout << ans << "\n";
    return 0;
}
```
#### P3817 [小 A 的糖果](https://www.luogu.com.cn/problem/P3817 "小 A 的糖果")

- 从左到右贪心修改
- 当前选择只影响相邻位置

核心思路是维护：

```
a[i-1] + a[i] <= x
```

超出时，优先减少当前元素。
```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 2e5 + 5;
int a[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,x;
    cin >> n >> x;

    for(int i=1; i<=n; i++)
        cin >> a[i];


    long long ans=0;
    for(int i=2; i<=n; i++)
        if(a[i-1] + a[i] > x){
            int diff = a[i-1] + a[i] - x;
            ans += diff;
            a[i] = max(0,x - a[i-1]);  //注意非负数的分析
        }
    cout << ans;
    return 0;
}
```

## 9. 贪心不一定正确

硬币面值：

```text
1 3 4
```

凑出：

```text
6
```

使用贪心，每次选最大的硬币：

```text
4 + 1 + 1
```

需要 `3` 枚。

最优方案：

```text
3 + 3
```

只需要 `2` 枚。

说明：

> 局部最优不一定能推出全局最优。

所以使用贪心前必须证明。

## 10. 贪心与动态规划

| 贪心 | 动态规划 |
|---|---|
| 每一步选择当前最优 | 考虑多个状态和方案 |
| 通常不回退 | 会比较不同方案 |
| 复杂度通常较低 | 复杂度通常较高 |
| 必须证明贪心策略正确 | 通过状态转移求最优解 |

## 11. 做题自检

每道贪心题都要问：

1. 我每一步在贪什么？
2. 排序依据是什么？
3. 为什么当前选择最优？
4. 当前选择会不会影响后续？
5. 是否存在反例？
6. 如何证明正确性？
7. 是否需要优先队列？

## 12. 一句话总结

> 贪心不是简单地每次选最大或最小，而是选择一个能够被证明通向全局最优的局部最优方案。

#### P4447 [[AHOI2018初中组] 分组](https://www.luogu.com.cn/problem/P4447 "[AHOI2018初中组] 分组")  ♥
```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1e5+5;
using MinHeap = priority_queue<int, vector<int>, greater<int>>;
int a[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    for(int i=1; i<=n; i++)  cin >> a[i];

    sort(a+1, a+1+n);

    int previous=0; //在每一个元素都需要更新维护previous
    int ans = n;  //ans初始先设置最大的值
    bool first = true; //因为previous初始是乱设的，所以第一次previous不可以起作用，那么需要区分第一次
    int i=1; //对于每一个元素都需要处理
    MinHeap groups;
    while(i<=n){
        int x = previous + 1;

        MinHeap next; //加入新优先队列防止产生二次干扰
        
        //统计个数
        int r=i;
        while(r<=n && a[r] == a[i]) r++;
        int cnt = r-i;
        
        //如果在当前位置需要间断
        if(first || a[i] != x){
            if(!groups.empty()){
                ans = min(ans, groups.top());  //取出最小值更新答案
                groups = MinHeap();  //清空防止对下一次产生干扰
            }
            for(int k=1; k<=cnt; k++)
                next.push(1);
        }else{//连续时
            //先扩大个数小的旧队列
            int used = 0;
            while(used < cnt && !groups.empty()){
                int len = groups.top();
                groups.pop();
                next.push(len+1);
                used++;
            }

            //看是否有剩下的队列，剩下的就中断了
            if(used == cnt && !groups.empty()){ //有剩下的队列
                ans = min(ans,groups.top());
                groups = MinHeap();
        }else{//没有剩下的旧队列了，那么新元素重新入队
                while(used < cnt){
                    next.push(1);
                    used++;
                }
        }
    }
        //更新相关值
        first = false;
        previous = a[i];
        i=r;
        groups.swap(next); //next成为新的group    
  }
    if(!groups.empty())
        ans = min(ans,groups.top());

    cout << ans;
    return 0;
}
    
```

# P4447 分组

## 题型

贪心 + 排序 + 小根堆

---

## 核心目标

把所有人分成若干组，每组实力值必须连续且不能重复，使最小组人数尽量大。

---

## 贪心策略

处理当前实力值 `x` 时：

- 只能接到以 `x-1` 结尾的小组后面
- 若有多个可接小组，优先延长长度最短的组
- 多余的人新建长度为 `1` 的组
- 没被延长的旧组直接结束

原因：

> 优先补最短组，更有利于提高最终最小组长度。

---

## 状态设计

```cpp
MinHeap groups;
表示：

> 所有以上一个实力值结尾的小组长度。

```cpp
MinHeap next;
```

表示：

> 加入当前实力值后形成的新小组长度。

不能直接放回 `groups`，否则同一个实力值可能被同一组使用多次。

---

## 处理流程

先排序，并统计当前相同实力值出现次数 `cnt`。

### 不连续

若：

```cpp
first || a[i] != previous + 1
```

则：

- 旧组全部结束
    
- 当前 `cnt` 个人各自新建长度为 `1` 的组
    

### 连续

优先延长最短旧组：

```cpp
while(used < cnt && !groups.empty()){
    int len = groups.top();
    groups.pop();

    next.push(len + 1);
    used++;
}
```

剩余旧组结束：

```cpp
if(!groups.empty())
    ans = min(ans, groups.top());
```

多余当前元素新建组：

```cpp
while(used < cnt){
    next.push(1);
    used++;
}
```

最后：

```cpp
groups.swap(next);
```

---

## 关键细节

```cpp
while(r <= n && a[r] == a[i])
    r++;
```

当前相同值区间为：

```text
[i, r-1]
```

出现次数：

```cpp
int cnt = r - i;
```

更新上一种实力值：

```cpp
previous = a[i];
```

---

## 复杂度

```text
排序：O(n log n)
堆操作：O(n log n)
总复杂度：O(n log n)
```

---

## 一句话总结

> 每个实力值优先接到当前最短的可延长小组后面，不能延长的组立即结束。
