## 适用场景

**特征：**

- 多次区间求和
- 数组不发生修改（**静态查询**）

例如：

- 区间和
- 子数组和
- 二维矩阵求和

---

## 核心思想

用 `pre[i]` 表示 **前 i 个元素的和**。

定义：

```cpp
pre[0] = 0;
for (int i = 1; i <= n; i++)
    pre[i] = pre[i - 1] + a[i];
```

---

## 区间求和

区间 `[l,r]` 的和：

```cpp
sum = pre[r] - pre[l - 1];
```

含义：

> 前 `r` 个元素之和 - 前 `l-1` 个元素之和。

查询复杂度 **O(1)**。

---

## 模板

### 构造前缀和

```cpp
pre[0] = 0;
for (int i = 1; i <= n; i++)
    pre[i] = pre[i - 1] + a[i];
```

### 查询区间和

```cpp
cout << pre[r] - pre[l - 1];
```

---

## 复杂度

| 操作 | 复杂度 |
|------|--------|
| 构造前缀和 | O(n) |
| 单次查询 | O(1) |
| 总复杂度 | O(n + m) |

空间复杂度：`O(n)`

---

## 易错点

- `pre[0] = 0` 必须初始化。
- 查询公式是 `pre[r] - pre[l - 1]`，不是 `pre[r] - pre[l]`。
- 推荐数组从 **1** 开始存储。
- 前缀和建议使用 `long long`，防止数据溢出。

---

## 与差分的区别

| 前缀和 | 差分 |
|--------|------|
| 多次区间查询 | 多次区间修改 |
| 查询 O(1) | 修改 O(1) |
| 修改 O(n) | 恢复 O(n) |

记忆口诀：

> **前缀和：快速查询。**  
> **差分：快速修改。**

---

## 经典题

#### P8218 区间和（模板）
```cpp
#include <iostream>
using namespace std;

const int N = 100000 + 5;

int a[N];
long long pre[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];
    }

    int m;
    cin >> m;

    while (m--) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << '\n';
    }

    return 0;
}
```

# 二维前缀和（2D Prefix Sum）

## 一、适用场景

**关键词：**

- 多次查询矩形区域和
- 固定/任意矩形求和
- 矩阵求最大（最小）子矩形和（固定大小）

当需要 **O(1)** 查询任意矩形元素和时，使用二维前缀和。

---

## 二、状态定义

设原矩阵为：

```cpp
arr[i][j]
```

表示：

> 第 i 行、第 j 列的真实值。

定义：

```cpp
pre[i][j]
```

表示：

> 从 `(1,1)` 到 `(i,j)` 的矩形元素和。

即：

```
(1,1) ────────── (1,j)
  │               │
  │     pre       │
  │               │
(i,1) ────────── (i,j)
```

---

## 三、初始化

第一行、第一列默认为 0。

构造二维前缀和：

```cpp
pre[i][j]
=
pre[i-1][j]
+
pre[i][j-1]
-
pre[i-1][j-1]
+
arr[i][j];
```

### 理解

```
当前矩形
=
上方矩形
+
左方矩形
-
重复计算的左上矩形
+
当前元素
```

---

## 四、查询任意矩形和（核心）

设矩形：

```
左上：(x1,y1)

右下：(x2,y2)
```

则：

```cpp
sum =
pre[x2][y2]
-
pre[x1-1][y2]
-
pre[x2][y1-1]
+
pre[x1-1][y1-1];
```

### 图示

```
┌──────────────┐
│██████████████│
│██████████████│
│██┌────────┐██│
│██│ 目标矩形 │██│
│██└────────┘██│
└──────────────┘
```

计算过程：

```
整个矩形
-
上方
-
左方
+
重复减去的左上
```

---

## 五、固定大小矩形

若边长为 C：

左上：

```
(i,j)
```

右下：

```
(i+C-1,j+C-1)
```

直接套公式：

```cpp
sum =
pre[i+C-1][j+C-1]
-
pre[i-1][j+C-1]
-
pre[i+C-1][j-1]
+
pre[i-1][j-1];
```

---

## 六、时间复杂度

建立前缀和：

```
O(NM)
```

查询一次：

```
O(1)
```

若枚举所有左上角：

```
O(NM)
```

总复杂度：

```
O(NM)
```

---

# CSP 常见题型

### ① 固定大小矩形最大和

例如：

- P2004 领地选择

做法：

```
二维前缀和
+
枚举左上角
```

---

### ② 多次矩形求和

例如：

```
询问若干矩形元素和
```

做法：

```
二维前缀和
```

---

### ③ 判断某个矩形是否合法

例如：

```
矩形内元素个数
矩形内障碍数量
矩形内金币数量
```

仍然：

```
二维前缀和
```

---

# 易错点（★★★★★）

### ① 前缀和公式漏写自身

错误：

```cpp
pre=
上+左-左上
```

正确：

```cpp
pre=
上+左-左上+arr[i][j]
```

---

### ② 查询公式写错

牢记模板：

```cpp
pre[x2][y2]
-pre[x1-1][y2]
-pre[x2][y1-1]
+pre[x1-1][y1-1]
```

不要自己推。

---

### ③ 左上角不是 (1,1)

查询时一定减：

```
x1-1

y1-1
```

不是：

```
x2-1
```

---

### ④ 行列不要写反

输入：

```cpp
for(i=1;i<=n;i++)
    for(j=1;j<=m;j++)
```

不要写成：

```cpp
j<=n
```

---

### ⑤ 最大值/最小值

根据题目决定：

```cpp
>
```

还是

```cpp
<
```

---

# 一维 vs 二维

| 一维前缀和 | 二维前缀和 |
|------------|-----------|
| pre[i] | pre[i][j] |
| 区间和 | 矩形和 |
| O(1) 查询区间 | O(1) 查询矩形 |

---

# 一句话总结

> **二维前缀和 = 用 O(NM) 预处理，使任意矩形元素和都能 O(1) 求出。**
# P2004 领地选择

## 题型

二维前缀和（固定大小矩形最值）
## 特征

- 给定一个矩阵
- 多次计算矩形元素和
- 矩形大小固定（C×C）
- 求最大/最小矩形和

→ 使用二维前缀和

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1e3 + 5;

long long prefix[N][N];
int arr[N][N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, c;
    cin >> n >> m >> c;
    //输入矩阵的值
    for(int i=1; i<=n; i++){
        for(int j=1; j<=m; j++)
            cin >> arr[i][j];
    }

    //构造前缀和
    for(int i=1; i<=n; i++){
        for(int j=1; j<=m; j++)
            prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + arr[i][j];
    }

    //进行查询并且比较大小
    int X = 1,Y = 1;
    long long ans =  prefix[c][c];
    for(int i=1; i<=n-c+1; i++){
        for(int j=1; j<=n-c+1; j++){
            long long current_value;
            current_value = prefix[i+c-1][j+c-1] - prefix[i-1][j+c-1] - prefix[i+c-1][j-1]
            + prefix[i-1][j-1];
            if(current_value > ans){
                X = i;
                Y = j;
                ans = current_value;
            }
        }
    }
    cout << X << " " << Y << "\n";
    return 0;
}
```
