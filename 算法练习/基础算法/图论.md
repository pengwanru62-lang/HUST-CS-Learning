# 图论入门：图的存储、DFS 与 BFS

## 1. 什么是图（Graph）

图由 **点（Vertex）** 和 **边（Edge）** 组成。

例如：

```text
1 → 2
↓
3 → 4
```

其中：

- 点：1、2、3、4
- 边：1→2、1→3、3→4

---

## 2. 图的分类

### 无向图

```text
1 —— 2
```

建边：

```cpp
graph[1].push_back(2);
graph[2].push_back(1);
```

---

### 有向图

```text
1 → 2
```

建边：

```cpp
graph[1].push_back(2);
```

**不能反向建边。**

---

## 3. 图的存储——邻接表

数据范围较大时使用邻接表：

```cpp
const int N = 1e5 + 5;
vector<int> graph[N];
```

含义：

```cpp
graph[x]
```

表示：

> 与节点 `x` 相邻的所有节点。

加入一条边：

```cpp
graph[x].push_back(y);
```

---

## 4. 为什么不用邻接矩阵

邻接矩阵：

```cpp
int g[N][N];
```

空间复杂度：

```text
O(n²)
```

当：

```text
n = 100000
```

需要：

```text
100000 × 100000
```

空间无法接受。

邻接表：

```text
O(n + m)
```

适用于大多数图论题。

---

## 5. 图上的 DFS

### 状态

```cpp
dfs(current)
```

表示：

> 当前访问节点 `current`。

---

### 模板

```cpp
bool visited[N];

void dfs(int current){
    visited[current] = true;
    cout << current << ' ';

    for(int next : graph[current]){
        if(!visited[next]){
            dfs(next);
        }
    }
}
```

---

### 思想

```text
访问当前节点
        ↓
枚举所有邻居
        ↓
没有访问过
        ↓
继续 DFS
```

---

## 6. 图上的 BFS

### 队列保存

```cpp
queue<int> q;
```

保存：

```text
节点编号
```

---

### 模板

```cpp
bool visited[N];

void bfs(int start){

    queue<int> q;

    q.push(start);
    visited[start] = true;

    while(!q.empty()){

        int current = q.front();
        q.pop();

        cout << current << ' ';

        for(int next : graph[current]){

            if(visited[next])
                continue;

            visited[next] = true;

            q.push(next);
        }
    }
}
```

---

## 7. 为什么 BFS 要在入队时标记

正确：

```cpp
visited[next] = true;
q.push(next);
```

避免：

```text
同一个节点重复进入队列
```

---

## 8. 为什么要排序

题目要求：

```text
优先访问编号较小的节点
```

因此：

```cpp
for(int i = 1; i <= n; i++){
    sort(graph[i].begin(), graph[i].end());
}
```

排序后：

```text
DFS、BFS 都会优先访问编号较小的节点。
```

---

## 9. 图搜索流程

```text
读入点和边
        ↓
建立邻接表
        ↓
排序邻接表（若题目要求）
        ↓
DFS / BFS
```

## 10. 网格搜索 vs 图搜索

### 网格搜索

下一状态：

```cpp
nx = x + dx[i];
ny = y + dy[i];
```

依靠：

```text
方向数组
```

---

### 图搜索

下一状态：

```cpp
for(int next : graph[current])
```

依靠：

```text
邻接表
```

## 11. DFS 与 BFS 对比

| DFS | BFS |
|------|------|
| 深度优先 | 广度优先 |
| 递归 / 栈 | 队列 |
| 一条路走到底 | 一层一层扩展 |
| 搜索所有方案 | 无权图最短路 |
#### P5318[【深基18.例3】查找文献](https://www.luogu.com.cn/problem/P5318 "【深基18.例3】查找文献")(图的dfs和bfs)
```cpp
#include<bits/stdc++.h>
using namespace std;

int n, m;
const int N = 1e5 + 5;
int bfs_visited[N];    //标记dfs是否被访问过
int dfs_visited[N];    //标记bfs是否被访问过

vector<int> graph[N];    //储存邻接矩阵

void dfs(int start){
    dfs_visited[start] = 1;

    cout << start << " ";

    //列举所有情况
    for(int next : graph[start]){
        if(dfs_visited[next])
            continue;
        dfs(next);
    }
}

void bfs(int start){
    //创造队列
    queue<int> q;

    //队列初始化
    q.push(start);

    //入队时标记
    bfs_visited[start] = 1;

    while(!q.empty()){
        int current = q.front();
        q.pop();

        cout << current << " ";

        //bfs_visited[current] = 1;出队才标记可能会导致同一个节点被反复访问，所以需要入队时标记
        
        for(int next : graph[current]){
            if(bfs_visited[next])
                continue;
            q.push(next);

            //入队就标记
            bfs_visited[next] = 1;
        }
    }
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;

    while(m--){
        int x,y;
        cin >> x >> y;
        graph[x].push_back(y); //注意vector语法的使用
    }

    //排序便于按照从小到大的顺序输出
    for(int i=1; i<=n; i++)
        sort(graph[i].begin(), graph[i].end());

    //从1开始dfs
    dfs(1);

    cout << "\n";
    
    //从1开始bfs
    bfs(1);
    
    return 0;
}
```

## 12. 常见题型识别

看到：

```text
节点
边
引用关系
朋友关系
道路
课程关系
```

想到：

```text
图
```

进一步判断：

```text
遍历所有节点
        ↓
DFS / BFS
```

```text
最短步数（无权）
        ↓
BFS
```

```text
带权最短路
        ↓
Dijkstra
```

## 13. 时间复杂度

建图：

```text
O(m)
```

排序：

```text
O(m log m)
```

DFS：

```text
O(n + m)
```

BFS：

```text
O(n + m)
```

# 一句话总结

> 图搜索本质上就是把网格搜索中的“方向数组”替换为“邻接表”，DFS 用于遍历，BFS 用于无权图最短路。
