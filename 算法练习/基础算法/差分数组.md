## 适用场景

**特征：**

- 多次区间修改
- 最后统一查询结果
- 不需要每次修改后立即查询

例如：

- 区间加减
- 批量修改成绩
- 区间覆盖

---

## 核心思想

差分数组是**前缀和的逆运算**。

定义：

```cpp
diff[1] = prefix[1];
diff[i] = prefix[i] - prefix[i - 1];
```

恢复原数组：

```cpp
prefix[1] = diff[1];
for (int i = 2; i <= n; i++)
    prefix[i] = prefix[i - 1] + diff[i];
```

---

## 区间修改

区间 `[l,r]` 全部加 `k`：

```cpp
diff[l] += k;
diff[r + 1] -= k;
```

原因：

- 从 `l` 开始增加 `k`
- 到 `r+1` 取消影响

每次修改复杂度 **O(1)**。

---

## 模板

### 构造差分

```cpp
diff[1] = prefix[1];
for (int i = 2; i <= n; i++)
    diff[i] = prefix[i] - prefix[i - 1];
```

### 区间修改

```cpp
diff[l] += k;
diff[r + 1] -= k;
```

### 恢复数组

```cpp
prefix[1] = diff[1];
for (int i = 2; i <= n; i++)
    prefix[i] = prefix[i - 1] + diff[i];
```

---

## 复杂度

| 操作 | 复杂度 |
|------|--------|
| 构造差分 | O(n) |
| 单次区间修改 | O(1) |
| 恢复数组 | O(n) |
| 总复杂度 | O(n + m) |

---

## 易错点

- `b[r+1]` 可能越界，数组需多开一个位置。
- 差分数组不是最终结果，必须前缀和恢复。
- `b[1] = a[1]`，第一项单独处理。
- 多次区间求和——前缀和；多次区间修改——差分
---

## 经典题

#### P2367 语文成绩（模板）
思路：构造差分数组 → 区间修改 → 前缀和恢复 → 统计最小值。
```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 5000005;

int a[N];
int b[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, p;
    cin >> n >> p;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    // 构造差分数组
    b[1] = a[1];
    for (int i = 2; i <= n; i++) {
        b[i] = a[i] - a[i - 1];
    }

    // 区间修改
    while (p--) {
        int x, y, z;
        cin >> x >> y >> z;
        b[x] += z;
        b[y + 1] -= z;
    }

    // 恢复数组并求最小值
    int ans = b[1];
    a[1] = b[1];

    for (int i = 2; i <= n; i++) {
        a[i] = a[i - 1] + b[i];
        ans = min(ans, a[i]);
    }

    cout << ans << '\n';

    return 0;
}
```
#### P5638 【CSGRound2】光骓者的荣耀
```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1e6+5;

long long diff[N];
long long prefix[N];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,k;
    cin >> n >> k;

    //输入差分数组
    for(int i=1; i<=n-1; i++) cin >> diff[i];

    //构造前缀和数组
    for(int i=2; i<=n; i++){
        prefix[i] = prefix[i-1] + diff[i-1];
    }

    //枚举k并动态更新最小值
    long long ans = prefix[n];
    for(int i=1; i<= n-k; i++){
        int to = i+k;
        long long current_time = prefix[i] + prefix[n] - prefix[i+k];
        ans = min(ans, current_time);
    }
    
    // 如果 k >= n，可以直接从1传到n
    if (k >= n) {
        cout << 0 << "\n";
        return 0;
    }
    
    cout << ans << "\n";

    return 0;
}
```
# 二维差分（2D Difference）

## 适用场景

**特征：**

- 多次矩形区域修改
- 最后统一输出整个矩阵

例如：

- 地毯覆盖
- 矩形加值
- 二维区间修改

---

## 核心思想

二维差分是一维差分的推广。

不直接修改矩形中的所有元素，而是**只修改四个角**。

设需要将矩形

```text
(x1,y1) ~ (x2,y2)
```

全部加上 `k`。

`diff[x1][y1]+= k;`表示从这个位置右下角全部+k

更新方式：

```cpp
diff[x1][y1] += k;//表示从这个位置右下角全部+k
diff[x2 + 1][y1] -= k;//表示从这个位置右下角全部-k，就是终止在这个位置
diff[x1][y2 + 1] -= k;//表示从这个位置右下角全部-k，就是终止在这个位置
diff[x2 + 1][y2 + 1] += k; //加上减去中重复的部分
```

---

## 为什么修改四个角？

四个角分别表示：

```text
左上      +k   → 开始产生影响

左下      -k   → 停止向下影响

右上      -k   → 停止向右影响

右下      +k   → 补偿重复减去的部分（容斥原理）
```

可以理解为：

> **开始影响 → 停止纵向影响 → 停止横向影响 → 补回来。**

---

## 模板

```cpp
diff[x1][y1] += k;
diff[x2 + 1][y1] -= k;
diff[x1][y2 + 1] -= k;
diff[x2 + 1][y2 + 1] += k;
```

---

## 复杂度

设共有 `m` 次修改。

| 操作     | 复杂度   |
| ------ | ----- |
| 一次矩形修改 | O(1)  |
| m 次修改  | O(m)  |
| 恢复矩阵   | O(n²) |

总复杂度：

```text
O(m+n²)
```

---

## 易错点

- 四个角的位置容易写错。
- 注意使用 `x2+1`、`y2+1`。
- 数组大小至少开到 `n+2`，防止越界。
- 差分完成后必须恢复，不能直接输出。

---

## 与一维差分对应

| 一维 | 二维 |
|------|------|
| 区间修改 | 矩形修改 |
| 两个端点 | 四个角 |
| 前缀和恢复 | 二维前缀和恢复 |

---

## 经典题

#### P3397 地毯（模板）
```cpp
#include <iostream>
using namespace std;

const int N = 1005;

int diff[N][N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    while (m--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;

        diff[x1][y1]++;
        diff[x2 + 1][y1]--;
        diff[x1][y2 + 1]--;
        diff[x2 + 1][y2 + 1]++;
    }

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            diff[i][j] += diff[i - 1][j]
                        + diff[i][j - 1]
                        - diff[i - 1][j - 1];

            cout << diff[i][j] << " ";
        }
        cout << '\n';
    }

    return 0;
}
```

# 二维差分恢复

## 为什么需要恢复？

二维差分数组 `diff[][]` 只记录了每次修改的信息。

恢复后才能得到最终矩阵。

---

## 数学定义（推荐理解）

设：

- `diff[][]`：差分数组
	- `a[][]`：恢复后的矩阵，本质就是矩阵`[i][j]`对应的值

恢复公式：

```cpp
a[i][j]
=
a[i - 1][j]
+
a[i][j - 1]
-
a[i - 1][j - 1]
+
diff[i][j];
```

含义：

```text
上
+
左
-
左上（去重）
+
当前位置
```

本质：

> **二维前缀和（容斥原理）。**

---

## 比赛写法（CSP 推荐）

实际比赛一般不会再开 `a[][]`。

直接恢复到 `diff[][]`：

```cpp
diff[i][j] += diff[i - 1][j]
            + diff[i][j - 1]
            - diff[i - 1][j - 1];
```

恢复结束后：

> `diff[][]` 已经变成最终答案。

---

## 为什么两种写法等价？

因为：

```cpp
diff[i][j] += x;
```

等价于：

```cpp
diff[i][j] = diff[i][j] + x;
```

展开就是：

```cpp
diff[i][j]
=
diff[i][j]
+
diff[i - 1][j]
+
diff[i][j - 1]
-
diff[i - 1][j - 1];
```

与数学定义完全一致。

只是：

- 教材：使用两个数组（`diff` 和 `a`）
- 比赛：只使用一个数组（`diff`）

---

## 一维与二维恢复对应

### 一维

```cpp
a[i] = a[i - 1] + diff[i];
```

### 二维

```cpp
a[i][j]
=
a[i - 1][j]
+
a[i][j - 1]
-
a[i - 1][j - 1]
+
diff[i][j];
```

可以理解为：

> **二维恢复 = 一维恢复 + 容斥原理。**

---

## 恢复模板

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        diff[i][j] += diff[i - 1][j]
                    + diff[i][j - 1]
                    - diff[i - 1][j - 1];
    }
}
```
因为初始值相等

---

## 易错点

- 不要把恢复公式记成普通前缀和，它是**二维前缀和恢复差分**。
- `+当前位置` 不要漏掉。
- `-左上` 是为了去除重复计算。
- 恢复后 `diff[][]` 已经不是差分数组，而是最终答案。

---

## 一句话总结

> **二维差分负责快速修改，二维前缀和负责恢复答案。**

记住：

```text
二维差分（修改）
        ↓
二维前缀和（恢复）
        ↓
最终矩阵
```
