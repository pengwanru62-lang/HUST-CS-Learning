## 1. 什么是拓扑排序

拓扑排序：

> 对有向无环图（DAG）进行排序，使得每条边的起点一定排在终点前面。

适用条件：

- 有向图
- 无环（DAG）

## 3. 图的存储

邻接表：

```cpp
vector<int> graph[N];
```

入度：

```cpp
int indegree[N];
```

出度：

```cpp
int outdegree[N];
```

建图：

```cpp
graph[u].push_back(v);
indegree[v]++;
outdegree[u]++;
```

---

## 4. 为什么维护入度

入度：

```text
有多少条边指向当前节点
```

只有：

```text
入度 = 0
```

说明：

```text
没有前驱
可以立即处理
```

---

## 5. 拓扑排序模板

初始化：

```cpp
queue<int> q;

for(int i = 1; i <= n; i++){
    if(indegree[i] == 0)
        q.push(i);
}
```

循环：

```cpp
while(!q.empty()){

    int u = q.front();
    q.pop();

    for(int v : graph[u]){

        indegree[v]--;

        if(indegree[v] == 0)
            q.push(v);
    }
}
```

---

## 6. 为什么 indegree--

例如：

```text
1 → 3
2 → 3
```

开始：

```text
indegree[3] = 2
```

处理完：

```text
1
```

表示：

```text
1→3 已完成
```

于是：

```cpp
indegree[3]--;
```

继续处理：

```text
2
```

再次：

```cpp
indegree[3]--;
```

最终：

```text
indegree[3] = 0
```

说明：

> 所有前驱已经处理完成，可以开始处理 3。

## 7. DAG DP

拓扑排序最大的作用：

> 保证状态转移顺序正确。

最短路：

```cpp
dp[v] = min(dp[v], dp[u] + w);
```

最长路：

```cpp
dp[v] = max(dp[v], dp[u] + w);
```

路径数：

```cpp
dp[v] += dp[u];
```

都可以直接放在：

```cpp
for(int v : graph[u])
```

里面。

# 一句话总结

> 拓扑排序本质就是：不断取出入度为 0 的节点，删除它的出边，直到所有节点处理完成。DAG 上的 DP 本质就是在拓扑排序过程中进行状态转移。

#### P1137 [旅行计划](https://www.luogu.com.cn/problem/P1137 "旅行计划")(有向无环图使用拓扑排序)
```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 100000 + 5;
vector<int> graph[N];
int indegree[N];
int dp[N];    //表示从1到i最多可以游览的城市
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,m;
    cin >> n >> m;

    //建图
    while(m--){
        int u,v;
        cin >> u >> v;
        graph[u].push_back(v);
        indegree[v] ++;
    }

    //队列初始化
    queue<int> q;

    for(int i=1; i<=n; i++){
        if(indegree[i] == 0){
            dp[i] = 1;
            q.push(i);
        }
    }

    while(!q.empty()){
        int u = q.front();
        q.pop();

        for(int v : graph[u]){
            if(dp[v] < dp[u] + 1){
                dp[v] = dp[u] + 1;
            }
            indegree[v]--;
            if(indegree[v] == 0)
                q.push(v);
        }
    }

    for(int i=1; i<=n; i++)
        cout << dp[i] << endl;
    return 0;
}
```
